# Contributing to KicksHub

Thanks for your interest in contributing to KicksHub! We welcome bug reports, feature requests, and pull requests.

## How to contribute

1. Fork the repository
2. Create a branch for your change:
   - `git checkout -b feat/short-description` (features)
   - `git checkout -b fix/short-description` (bug fixes)
3. Commit with clear messages and use conventional commits when possible.
4. Push to your fork and open a Pull Request.

## Code style

- Use TypeScript where possible for the backend.
- Keep code readable and well-documented.
- Run linters and formatters before opening a PR.

## Pull Request checklist

- [ ] The PR has a clear title and description
- [ ] Tests (if any) pass locally
- [ ] Linter passes
- [ ] No secrets or credentials are included

## Reporting bugs

Open an issue with:
- A short descriptive title
- Steps to reproduce
- Expected vs actual behavior
- Screenshots/logs when applicable
